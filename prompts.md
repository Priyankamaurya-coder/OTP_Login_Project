# LLM Prompts Used During Project Development

This file contains the prompts used with an LLM while developing the OTP Based User Login project.

## Project Setup

1. "I want to build the OTP Login project based on the assignment requirements. Guide me step by step."

2. "Like first we create folder as OTP-login project inside this again I have to create new folder for frontend."

3. "For main folder I will use OTP_Login_Project."

## Backend Development

4. "Help me create the Django backend for the OTP login project."

5. "Create the registration API that collects email, first name and last name."

6. "Generate a random 6-digit OTP after successful registration."

7. "Create the API to recognize whether an email belongs to a registered user."

8. "Create the OTP verification API."

9. "Add OTP expiration and validate that the OTP is exactly 6 digits."

10. "Help me configure CORS between the React frontend and Django backend."

## Frontend Development

11. "Create the React frontend for registration and checkout."

12. "Add real-time email validation while the user types."

13. "When the email is recognized, show an OTP modal."

14. "Add a Skip Login option to the OTP modal."

15. "After successful OTP verification, display the user's name at the top of the checkout form."

16. "Provide the entire App.jsx code."

## Checkout Development

17. "The checkout form should collect email, phone number and shipping address."

18. "Add a Checkout model to save checkout data in the database."

19. "Create an API to save checkout information to the database."

20. "Connect the React checkout form to the Django checkout API."

21. "Provide the entire App.jsx code with checkout data saving."

## Database

22. "How do I clear the registered test user from the SQLite database?"

23. "How can I create the required SQL database schema file?"

24. "SQLite3 is not recognized in CMD. Show me another way to create the SQL schema."

## Testing

25. "How do I test the registration and OTP login flow?"

26. "How do I test the Skip Login flow?"

27. "How do I verify that checkout information is actually saved in the database?"
